# 🌙 Layl Chat — منصة دردشة صوتية ونصية (v2)

منصة دردشة عربية (RTL) فخمة بأجواء الليل: **مايكات صوتية حقيقية (WebRTC)**، غرف متعددة، خاص، حائط، وإعجابات — مبنية من الصفر.

## ✨ المميزات

**الصوت 🎙️ (الأبرز)**
- مقاعد مايك لكل غرفة — اصعد المايك وتكلّم بصوت حقيقي عبر **WebRTC**
- مؤشّر تحدّث متحرّك (هالة خضراء)، كتم المايك، كتم السماعات
- إشراف صوتي: إنزال عضو من المايك
- غرف صوتية وكتابية + سعة لكل غرفة + عدد مقاعد قابل للتخصيص

**الدردشة 💬**
- غرف متعددة + متصفّح غرف + إنشاء غرف
- رسائل لحظية (Socket.io) + "يكتب الآن" + رد/تعديل/حذف + تفاعلات + منشن + بحث + `/me`

**اجتماعي 👥**
- ✉️ رسائل خاصة (خاص) مع إشعار
- 📰 الحائط: منشورات عامة + إعجابات
- ❤️ الإعجاب بالأعضاء
- 👤 بطاقة بروفايل: أفاتار، لون اسم، حالة، دولة (علم)، روابط سوشيال، نبذة
- 🏆 نظام خبرة ومستويات (XP)
- 👑 رتب (مالك/مشرف/عضو) + 🔇 إشراف (كتم/حظر/ترقية)
- 🎨 4 ثيمات + سماء نجوم متحرّكة + رسائل ترحيب للغرف

**الأمان (مهم)**
- 🔐 كلمات مرور مشفّرة بـ bcrypt
- 🍪 جلسات JWT في كوكي `httpOnly` + `sameSite`
- 🧼 **حماية كاملة من XSS** — كل محتوى المستخدم يُعرض عبر عُقد نصّية (DOM text nodes)، لا `innerHTML`
- 🪖 Helmet + Content-Security-Policy
- 🚦 Rate limiting على الدخول/التسجيل + مكافحة سبام الرسائل (نافذة منزلقة)
- ✅ تحقّق من المدخلات على الخادم

## 🚀 التشغيل

```bash
cd chat
npm install
npm start
# افتح http://localhost:3000
```

أول حساب يُسجَّل يصبح **المالك (owner)** تلقائيًا.

> **للإنتاج:** عيّن متغيّرات البيئة:
> ```bash
> JWT_SECRET="سر-طويل-وعشوائي"  NODE_ENV=production  PORT=3000  npm start
> ```
> وشغّل خلف **HTTPS** (إلزامي: المايك `getUserMedia` لا يعمل إلا على HTTPS أو localhost، والكوكي يصبح `secure`).
>
> **ملاحظة WebRTC:** الصوت نظام *mesh* (مناسب للغرف الصغيرة/المتوسطة). للغرف الكبيرة جدًا يُفضّل إضافة خادم SFU (مثل mediasoup) لاحقًا. ولتجاوز الـ NAT في الإنتاج أضف خادم TURN.

## 🧱 البنية

| الملف | الوظيفة |
|------|---------|
| `server.js` | خادم Express + Socket.io، المصادقة، الـ API، كل منطق اللحظي والإشراف |
| `db.js` | قاعدة بيانات SQLite (مستخدمون، غرف، رسائل، تفاعلات) |
| `public/index.html` | هيكل الواجهة |
| `public/styles.css` | التصميم (ثيم الليل، RTL، استجابة الجوال) |
| `public/app.js` | منطق العميل + السوكِت + العرض الآمن |

## 🧪 الاختبار

تم اختبار التطبيق بـ Playwright (عميلان متزامنان): تأكيد التسليم اللحظي، حجب XSS،
التواجد، والعرض على سطح المكتب والجوال.

التقنية: Node.js · Express · Socket.io · SQLite (better-sqlite3) · bcrypt · JWT
