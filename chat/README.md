# 🌙 Layl Chat — منصة دردشة لحظية

منصة دردشة عربية (RTL) فخمة بأجواء الليل، لحظية بالكامل عبر WebSocket، مبنية من الصفر.

## ✨ المميزات

**أساسية**
- 💬 غرف متعددة + إنشاء غرف جديدة
- ⚡ رسائل لحظية (Socket.io) + مؤشّر "يكتب الآن"
- 👥 قائمة المتواجدين لحظيًا لكل غرفة
- ↩️ الرد على رسالة (اقتباس) + ✏️ تعديل + 🗑️ حذف رسائلك
- 😀 تفاعلات بالإيموجي على الرسائل
- 🔔 منشن `@username` مع إشعار صوتي
- 🔍 بحث داخل رسائل الغرفة
- `/me` و `/shrug` (أوامر مائلة)

**أفكار قوية**
- 🏆 نظام خبرة ومستويات (XP) — كل رسالة تعطيك خبرة، وترتقي بالمستوى مع احتفال
- 🎨 4 ثيمات (ليل / غروب / محيط / غابة) + سماء نجوم متحرّكة
- 👤 ملف شخصي: أفاتار، لون، حالة/فايب، نبذة
- 🛡️ نظام رتب: مالك / مشرف / عضو
- 🔇 إشراف: كتم مؤقّت، حظر، ترقية مشرفين

**الأمان (مهم)**
- 🔐 كلمات مرور مشفّرة بـ bcrypt
- 🍪 جلسات JWT في كوكي `httpOnly` + `sameSite`
- 🧼 **حماية كاملة من XSS** — كل محتوى المستخدم يُعرض عبر عُقد نصّية (DOM text nodes)، لا `innerHTML`
- 🪖 Helmet + Content-Security-Policy
- 🚦 Rate limiting على الدخول/التسجيل + مكافحة سبام الرسائل (نافذة منزلقة)
- ✅ تحقّق من المدخلات على الخادم

## 🚀 التشغيل

```bash
cd chat
npm install
npm start
# افتح http://localhost:3000
```

أول حساب يُسجَّل يصبح **المالك (owner)** تلقائيًا.

> **للإنتاج:** عيّن متغيّرات البيئة:
> ```bash
> JWT_SECRET="سر-طويل-وعشوائي"  NODE_ENV=production  PORT=3000  npm start
> ```
> وشغّل خلف HTTPS (الكوكي يصبح `secure`).

## 🧱 البنية

| الملف | الوظيفة |
|------|---------|
| `server.js` | خادم Express + Socket.io، المصادقة، الـ API، كل منطق اللحظي والإشراف |
| `db.js` | قاعدة بيانات SQLite (مستخدمون، غرف، رسائل، تفاعلات) |
| `public/index.html` | هيكل الواجهة |
| `public/styles.css` | التصميم (ثيم الليل، RTL، استجابة الجوال) |
| `public/app.js` | منطق العميل + السوكِت + العرض الآمن |

## 🧪 الاختبار

تم اختبار التطبيق بـ Playwright (عميلان متزامنان): تأكيد التسليم اللحظي، حجب XSS،
التواجد، والعرض على سطح المكتب والجوال.

التقنية: Node.js · Express · Socket.io · SQLite (better-sqlite3) · bcrypt · JWT
